## 📋 Gestures Guide
| Gesture | Action |
| --- | --- |
| Index finger up | Move cursor |
| Index + Thumb pinch | Left click |
| Index + Middle pinch | Right click |
| All fingers close | No action |
| Palm open | Stop tracking |
